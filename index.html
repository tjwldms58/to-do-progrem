업무관리 처음 설정

Firebase 연결 정보가 아직 없어요. 아래 순서대로 한 번만 설정하면 됩니다.

  1. Firebase 새 프로젝트 만들기 — console.firebase.google.com 에서 프로젝트 추가.
  2. Realtime Database 만들기 — 빌드 → Realtime Database → 데이터베이스 만들기 → 위치 싱가포르(asia-southeast1) → 잠금 모드. 그다음 규칙 탭에 아래를 붙여넣고 게시: 
    {
  "rules": {
    "workmgr": {
      "$uid": {
        ".read":  "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    }
  }
}
  3. Google 로그인 켜기 — 빌드 → Authentication → 시작하기 → 로그인 방법 → Google 사용 설정.
  4. Google Calendar API 켜기 — console.cloud.google.com 에서 같은 프로젝트 선택 → API 및 서비스 → 라이브러리 → "Google Calendar API" 사용. 이어서 OAuth 동의 화면(데이터 액세스에 calendar.events, calendar.calendarlist.readonly 범위 추가)에서 사용자 유형을 내부(회사 Google Workspace 계정일 때) 또는 외부+테스트 사용자에 본인 이메일 추가.
  5. 웹 앱 등록 — 프로젝트 설정(톱니바퀴) → 내 앱 → 웹(</>) 추가 → 나오는 firebaseConfig를 이 파일의 FIREBASE CONFIG 부분에 붙여넣기. (지금 이 브라우저에서만 쓰려면 아래 칸에 붙여넣어도 돼요.)
  6. 웹 주소에서 열기 — 파일을 더블클릭해 열면 구글 로그인이 막혀요. Firebase Hosting에 올리거나(firebase deploy), 다른 주소를 쓰면 Authentication → 설정 → 승인된 도메인에 추가하세요.
